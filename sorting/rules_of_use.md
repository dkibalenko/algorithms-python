1. Insertion sort should be used if input it **small** or items are mostly **sorted**. Then it's fast, best: Time $O(n)$, worst: Time $O(n^2)$, Space $O(1)$
2. Merge sort is really good. Time $O(n\space log\space n)$, Space $0(n)$
3. Quick sort is a bit better than merge sort with memory, Space $0(log(n))$, but worst Time can be $O(n^2)$
